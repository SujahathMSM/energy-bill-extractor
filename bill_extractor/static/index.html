How it works

The model only reads. Everything that can be calculated is calculated in code, so a misread digit shows up as a sum that doesn't add up.

  1. 1

    Prepare the file

    PDF pages are rendered to images. Photos are turned upright using their EXIF data and resized.

    pypdfium2, Pillow
  2. 2

    Read the bill

    A vision model copies each field exactly as printed, in its original units. Anything not on the bill is left empty.

    Claude, OpenAI-compatible models or Ollama
  3. 3

    Validate the reply

    The reply is checked against a schema. If it doesn't fit, the errors go back to the model for one more attempt.

    Pydantic
  4. 4

    Check the numbers

    Code converts pence to pounds, reconciles rates, readings and totals, and tests the MPAN check digit. Any failure marks the bill for review.

    Plain Python, no model
